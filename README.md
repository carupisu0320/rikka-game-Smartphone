# 六華（リッカ）オンライン対戦 - スマートフォン版

麻雀の体験をシンプルに再構築したボードゲーム「六華」のオンライン対戦実装、スマートフォン向けPWA（ホーム画面に追加できるアプリ）版です。

ゲームルールやサーバーの仕組みは[PC版（rikka-game）](https://github.com/carupisu0320/rikka-game)と同じで、こちらはスマートフォンでの利用に特化した設定（フルスクリーン表示・ホーム画面への追加対応など）が入っています。

## 📱 今すぐ遊ぶ

👉 **[https://carupisu0320.github.io/rikka-game-Smartphone/](https://carupisu0320.github.io/rikka-game-Smartphone/)**

スマートフォンのブラウザで開いたあと、共有メニューから「ホーム画面に追加」を選ぶと、アプリのようにフルスクリーンで起動できます。

## 🎆 ゲームルール

### 概要
- プレイ人数：2〜5人
- 目標：設定した点数（5 / 10 / 15 / 20 / 30 から選択、デフォルト10点）を先取したプレイヤーが勝利

### 牌について
リッカ牌はドミノ牌で、上下に1〜6のシンボルが描かれています。
手牌の「上」の面を使って役を作りますが、牌を**反転**させると上下が入れ替わります。
上下の数字が同じ牌（例: 上3・下3）は**★ゾロ目牌**と呼ばれ、ボーナスの対象になります。

### 手番の流れ
1. 場の牌を1枚選んで引く（裏向き山札 or 表向き場から）
2. 手牌6枚から不要な1枚を捨てる（表向きで場に置く）
3. 役が完成したら「上がる！」を宣言

### 役の種類（基本役・常に有効）
| 役名 | 条件 | 点数 |
|------|------|------|
| 一色 | 6枚の下の数をすべて同じに（上は何でもOK） | 2点 |
| 三連 | 「下が同じ3枚＋上が連番」のセットを2組 | 3点 |
| 六華 | 6枚の下の数が同じ＋上が1〜6の連番 | 6点 |

### 役の種類（追加役・ロビーでON/OFF可能）
| 役名 | 条件 | 点数 |
|------|------|------|
| 三対 | 6枚を同じ牌のペア×3組にする | 5点 |
| 三色 | 全牌の上下の数を3種類のみにする（ボーナスなし・ついでに完成でのみ成立） | 3点 |
| 輝光 | 6枚すべてを★ゾロ目牌にする（ボーナスなし） | 5点 |
| 無双 | ★ゾロ目牌を6種類すべて集める | 3点＋★ボーナス |

### ★輝きボーナス
上がったとき、手牌に★ゾロ目牌（上下が同じ数字の牌）があると、その枚数分だけ役の点数に**+1点ずつ**追加される（輝光・三色を除く）。

### 追加ルール（ロビーでON/OFF可能）
- **ついでに完成**：誰かが上がった後、表向きの捨て牌と自分の手牌を組み合わせて役が完成していれば、その得点がもらえる。
- **リーチ**：捨てればテンパイ（あと1枚で上がれる状態）になるときに宣言可能。以降は自動で捨て牌され、上がると+1点（ついでに完成での完成にも乗る）。
- **ロン**：他のプレイヤーが捨てた牌で自分の役が完成するなら宣言可能。手番順を無視してその牌をもらい、その場で上がれる。
  - 得点（役点＋ボーナス）はストックからではなく、**捨てた本人の得点チップ**から奪う。
  - 相手の点数が足りない場合は**奪えるだけ奪う**（相手が0点なら何ももらえない）。
  - 2人以上が同時にロンを宣言した場合は、**捨てた人から時計回りで最も近い1人のロンだけが有効**。

## 🚀 セットアップ

### 必要環境
- Node.js 18以上

### インストール
```bash
npm install
```

### ローカル起動
```bash
npm start
```
ブラウザで `http://localhost:3000` を開いてください。

